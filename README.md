# 邮箱助手 (Email Helper)

> 批量一对一精准邮件投递桌面工具（EXE 桌面客户端）。支持主发件邮箱配置、富文本正文格式化、动态变量替换、一对一附件绑定、多线程并发连接池、分类自动重试与全流程明细审计。

---

## 一、界面与交互设计

软件采用专为桌面环境设计的直观双栏工作台布局，操作流程紧凑连贯，所见即所得：

1. **沉浸式原生窗口 (`DesktopTitlebar`)**：
   - 支持窗口拖拽与原生 Windows 最小化、最大化、关闭控制。
   - 顶部集成发信工作台与任务记录的双态切换器。
   - 发件箱连通状态实时指示，一键快速定位本地附件目录。
2. **一体化发信工作台 (`WorkspaceView`)**：
   - **左栏（收件名单与专属附件列表）**：支持文件扫描自动提取、表格拖拽直接解析（Excel/CSV）、手动录入与收件人信息就地编辑，清晰显示收件人、邮箱、绑定附件文件名、大小及存在性状态。
   - **右栏（邮件排版与所见即所得画布）**：
     - 主题与正文：原生输入框，支持富文本排版、本地图片上传插入、系统截图直接 `Ctrl + V` 粘贴。
     - 动态变量：支持在正文中插入 `{{recipientName}}`、`{{recipientEmail}}`、`{{attachmentName}}`、`{{sendDate}}`，发送时自动替换为每位收件人的专属信息。
     - 效果预览：支持在左侧点击不同收件人，右侧即刻实时联动渲染出该收件人收到时的真实邮件排版与附件效果。
     - 底栏：正文内容实时自动保存，支持一键发送单封测试邮件到发件人自己的邮箱查验效果。
   - **底部全局控制栏 (`Command Bar`)**：
     - 实时汇总待发送数量、异常数量与预估发送耗时。
     - 发送并发线程数与调度间隔快捷调节。
     - 醒目的一键批量发送主操作按钮。
3. **实时发信监控与审计抽屉 (`ExecutionDrawer`)**：
   - 启动发送后自动滑出执行面板，实时展示总体进度条、完成度百分比与分类状态统计（SMTP 已接收、失败、待确认等）。
   - 逐封投递流水：展开可查阅 SMTP Message-ID、原始错误分类、重试次数与尝试记录。
   - 提供暂停、继续、终止与一键重试失败项功能。
4. **轻量本地化存储与安全保护**：
   - 采用纯本地 JSON 配置与原子文件替换机制，无需配置任何外部数据库，便携目录随拷随走。
   - 发件箱密码采用操作系统级安全加密（Windows safeStorage）持久化存储，不裸存明文密码，日志自动脱敏。
   - 附件严格限定在运行目录同级的 `mail-files/` 文件夹中，防止路径越界。

## 二、开发与构建

```bash
# 1. 安装依赖
npm install

# 2. 启动本地桌面客户端调试
npm run dev

# 3. 打包 Windows 绿色便携版 (Portable EXE)
npm run dist:portable

# 4. 打包 Windows 安装版 (Setup EXE)
npm run dist:win
```
