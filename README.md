# 邮箱助手 (Email Helper)

> 批量一对一精准邮件投递桌面工具（EXE 桌面客户端）。支持主发件邮箱配置、富文本正文格式化、动态变量替换、一对一附件绑定、多线程并发连接池、分类自动重试与全流程明细审计。

---

## 一、现代桌面客户端架构设计 (Desktop Studio)

摒弃传统 Web 管理后台（ERP/SaaS 若依式左右大菜单及多页面反复跳转），采用对标 **VS Code / TablePlus / Linear** 顶级桌面工具的一体化工作室架构：

1. **无边框沉浸式原生标题栏 (`DesktopTitlebar`)**：
   - 支持窗口拖拽 (`-webkit-app-region: drag`) 与原生 Windows 最小化/最大化/关闭按钮。
   - 顶部集成发信工作台与执行审计的双态分段切换器 (`Segmented Control`)。
   - 实时发信箱连通状态指示器与附件目录一键直达。
2. **一体化发信工作台 (`WorkspaceView`)**：
   - **左栏（收件与附件清单）**：支持批量导入 Excel/CSV、手动录入、直接**拖拽表格文件入窗解析**，清晰展示姓名、邮箱、绑定附件文件名、大小及存在性（绿标/红标）。
   - **右栏（邮件排版与所见即所得画布）**：
     - 主题栏：原生主题输入 + 一键插入个性化动态变量 (`{{recipientName}}`、`{{recipientEmail}}`、`{{attachmentName}}`、`{{sendDate}}`)。
     - 视图切换：支持「正文编辑」与「效果预览（所见即所得）」。在左侧点击不同收件人，右侧即刻渲染出该客户专属的邮件与附件卡片。
     - 底栏：实时自动持久化指示与测试发信按钮。
   - **底部全局指令条 (`Command Bar`)**：
     - 待发就绪统计、预计耗时预估。
     - 并发线程数与调度间隔快捷旋钮。
     - 突出醒目的「开始批量发送」主行动按钮。
3. **实时发信监控与审计抽屉 (`ExecutionDrawer`)**：
   - 发送启动后自动滑出执行面板，展示总体进度条、速度指标与各状态统计药丸。
   - 逐封投递流水：展开可查阅 SMTP messageId、原始错误分类、重试次数与历史尝试。
   - 支持暂停、继续、终止、一键重试失败项与导出 Excel 审计报告。
4. **轻量无依赖存储**：
   - 移除 SQLite 原生二进制依赖，采用原子替换的 JSON 配置与增量 NDJSON 审计流水。
   - 密码采用 Windows `safeStorage` 系统级安全加密。
   - 运行同级 `mail-files/` 附件专属隔离，严防 `..` 越界穿透。

---

## 二、开发与构建

```bash
# 1. 安装依赖
npm install

# 2. 启动本地桌面客户端调试
npm run dev

# 3. 打包 Windows 绿色便携版 (Portable EXE)
npm run dist:portable

# 4. 打包 Windows 安装版 (Setup EXE)
npm run dist:win
```
