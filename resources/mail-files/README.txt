========================================================================
邮箱助手 (Email Helper) - 附件存放专属目录 (mail-files)
========================================================================

【使用说明】
1. 所有需要一对一绑定并随邮件发送的附件，请放置在本目录下（支持创建子目录，如 contracts/ 或 reports/）。
2. 在软件中配置映射或导入 Excel 时，附件路径填写相对本目录的相对路径。
   例如：
   若文件位于：mail-files/contracts/张三合同.pdf
   映射路径填写：contracts/张三合同.pdf

3. 严禁使用超出本目录范围的文件或 .. 跨级路径，以确保数据安全性与绿色移动便携性。
========================================================================
